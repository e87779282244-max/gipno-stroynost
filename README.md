# Гипно-стройность

30 дней перепрограммирования пищевого поведения. Авторская методика.

Приложение: https://e87779282244-max.github.io/gipno-stroynost/

- `index.html` — приложение (собирается из `src/`)
- `src/template.html` — код, `src/days.json` — план 30 дней, `src/secs.json` — справочник
- `sw.js` — офлайн-режим, `media/` — иконки и картинки упражнений
- Сборка: `python3 src/build.py`
